# Антибиотики: справочник клинического фармаколога

Версия 1.0. Автор проекта: Зулкашев Елдос Уахапович.

**Это только справочник. Окончательное решение принимает врач.** Клиническое содержание экспертную проверку не проходило; дозы сверяйте с инструкцией к препарату, клиническими протоколами МЗ РК и локальной антибиотикограммой.

Веб-приложение для врачей: возбудители и терапия, комбинации, противогрибковые, калькуляторы (мг и мл), детские дозы. После первого открытия работает без интернета.

Установка на iPhone: открыть адрес сайта в Safari → «Поделиться» → «На экран Домой».
